# Language Engine

Owns Paridhwani's complete language-learning and language-intelligence layer.

## Learning design

- Kannada curriculum, vocabulary, grammar, and contextual learning content
- English → Kanglish → Kannada progression
- Difficulty levels, learning objectives, and supportive feedback
- Learner skill tracking and practice rules

See [LEARNING_DESIGN.md](LEARNING_DESIGN.md) for the learning-design scope consolidated from the former Language & Learning repository.

## NLP and intelligence

- Informal Romanized Kannada (Kanglish), spelling variation, and code-mixing
- Transliteration between Kanglish and Kannada script
- Contextual NPC dialogue behavior
- Meaning-based learner-response evaluation and error categories
- Hints, correction feedback, and adaptive practice requirements

This repository is part of the Paridhwani master workspace and has its own independent Git history. No application code has been added yet.
